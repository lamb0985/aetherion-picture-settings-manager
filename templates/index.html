Devices and connection
New device: Prepare a new device entry. Save & select: Save the name, IP and ADB port and select it. Connect / refresh: Check ADB and refresh the selected device. The saved-device selector switches devices.


Picture settings
Picture: Native picture menus, luminance, color, clarity and calibration. Laser Settings: Projector-specific settings. Raw Diagnostics: Native attributes, values, ranges and states. Show native parameters and raw values: Display protocol details. Live synchronization: Read the current projector profile and enable supported adjustments. Signal format and Picture profile are disabled during Live synchronization because they reflect the projector’s actual incoming signal and active picture mode. This prevents browsing a different stored profile while editing the live one. Change the active picture mode through the Picture menu or projector remote. Disable Live synchronization to unlock both dropdowns and browse stored profiles without changing projector settings; re-enable it to return to the active profile. Arrows, sliders and option buttons adjust supported live settings; Back returns to the parent menu. Disabled reset and calibration actions are not implemented.


Utilities
Scan: Capture all supported profiles and indexed calibration tables on the current input; Cancel requests safe restoration. DB Source: Choose a stored input snapshot or import scanner JSON; Import replaces that snapshot. Bulk Apply: Preview a setting across selected profiles, then apply or cancel. Help: Open this guide.


Remote control
Start mirror / Stop: Start or stop scrcpy using the chosen resolution, bitrate and frame rate. Fullscreen: Expand video. Screenshot: Save a projector screenshot. Directional buttons and OK navigate; Back, Home, Menu, Quick Settings and Picture Settings open native screens; volume buttons adjust or mute sound; HDMI buttons select inputs. During scanning, the mirror is view-only.


Diagnostics
Live Log Viewer: Filter logs, toggle auto-scroll, pause/resume, copy or clear the displayed history. Command Console: Execute supported read-only commands (type help), copy or clear output. Arrow keys recall commands. Panel headings expand/collapse their contents.
